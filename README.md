# المحاسب الذكي اليمني
# Yemen Smart Accountant

تطبيق محاسبي عربي متكامل لنظام Android.

## المبادئ
- واجهة عربية RTL.
- قاعدة بيانات فارغة عند أول تشغيل.
- محاسبة بالقيد المزدوج.
- إدارة العملاء والموردين والأصناف والمخزون.
- الفواتير والديون وسندات القبض والصرف.
- التقارير المالية والاستيراد والتصدير.
- الاختبارات والبناء عبر GitHub Actions.

## التقنية
- Flutter
- SQLite
- GitHub Actions

لا تُعتمد أي بيانات تجريبية بوصفها بيانات حقيقية.
