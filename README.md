# المحاسب الذكي اليمني | Yemen Smart Accountant

تطبيق محاسبي عربي RTL لنظام Android، يجري تطويره على مراحل مع البناء والاختبار عبر GitHub Actions.

## الموجود في النسخة التأسيسية
- واجهة عربية RTL وصفحات الرئيسية والأطراف والأصناف والتقارير وبيانات المنشأة.
- قاعدة SQLite محلية تُنشأ فارغة عند أول تشغيل دون بيانات تجريبية.
- إدارة العملاء والموردين مع الهاتف والعنوان والرصيد الافتتاحي.
- إدارة الأصناف والوحدات وأسعار الشراء والبيع والكمية الافتتاحية.
- إعداد بيانات المنشأة والعملة الأساسية.
- مخطط أولي لدفتر اليومية وسطور القيود والسندات وحركات المخزون.
- قواعد مستقلة لاختبار توازن القيد المزدوج.
- GitHub Actions للتحليل والاختبارات وبناء APK ورفعه كـ Artifact.

## البناء
يبدأ البناء تلقائياً عند الدفع إلى الفرع main أو عبر تشغيل workflow يدوياً من تبويب Actions.

## تنبيه محاسبي
هذه نسخة تأسيسية قيد التطوير وليست نظاماً محاسبياً مكتملاً للاستخدام الإنتاجي. الفواتير والترحيل المحاسبي والسندات وحركات المخزون والتقارير المالية تحتاج إلى استكمال وربط واختبارات قبل اعتمادها. لا تعرض النسخة أرباحاً أو ميزانية محسوبة على أنها أرقام نهائية.

## المبادئ
- واجهة عربية واتجاه RTL.
- بيانات حقيقية يدخلها المستخدم فقط.
- المبالغ مخزنة كأعداد صحيحة بوحدات العملة الصغرى.
- مراجعة تراخيص المشاريع المرجعية قبل إعادة استخدام أي كود.
